# SpendSmart budgeting guidance

## Build a realistic budget
Start with reliable income and essential expenses. Separate needs from wants, then set category limits that reflect actual spending patterns. A budget is a planning tool, not a reason to skip necessary healthcare, food, housing, or education.

## Emergency savings
An emergency fund is intended for unexpected essential costs. Start with a manageable amount and build it gradually. Do not assume that every user can immediately save a fixed percentage of income.

## Review subscriptions
Check recurring subscriptions and memberships periodically. Recommend cancelling or downgrading only after the user confirms that a service is not needed.

## Interpret unusual transactions carefully
An unusually large or repeated transaction may deserve review, but an anomaly is not proof of fraud. Ask the user to verify unfamiliar activity using their bank's official application or contact channel.

## Savings targets
Calculate a savings target from the user's stated income and target rate. Compare the target with the actual income and expense data. If the data is incomplete or the target is not feasible, explain the uncertainty and suggest a more realistic alternative.

## Data quality
Transaction exports can omit pending transactions, cash spending, fees, or transfers. State the date range and coverage of the data. Never treat missing records as proof that no spending occurred.
